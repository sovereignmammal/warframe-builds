# Synoid Gammacor Incarnon

Primer / grouper. **Not Mesa** (Brakk). **Not Oraxia** (Scyotid). Pair with Torid / Burston / melee.

Enable **Fire Manual Trigger Weapons Continuously**. Beam = Overguard (Magnetic). Incarnon = 15m pull + Cold bombs.

**No Cold or Electric mods** — they eat innate Magnetic.

## Evolutions

- Infused Shots
- **Evolved Autoloader** — swap gun; reloads in the holster while Latron / Torid / Burston shoot
- Elemental Balance *(or Critical Parallel for bombs)*

## Mods

Hornet, Galvanized Diffusion, Lethal Torrent, Galvanized Shot, Scorch, Pistol Pestilence, Pistol Elementalist, Primed Pistol Gambit.

This is the **Encumber** hip if you want that arcane, not Scyotid.
