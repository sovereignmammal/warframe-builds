# Saryn — Lash / Spore

Keep **3** (Toxic Lash). Do not Helminth Molt unless you already live without it. Companion: **Aga Umbonek** (Voruna’s hound). **Juno Ty** is Garuda. Toxic Lash is melee.

## Config A — Sobek chain (no gate)

Kill with Lash on → Acid Shells explodes 15m → explosion applies Lash toxin → chain.

Aura **Growing Power** *(or Corrosive Projection)*. Exilus **Power Drift**.

Optional Helminth: **Roar over Miasma (4)** on this config only.

### Kuva Sobek

**Acid Shells** has to be on. Toxin mods (Contagious Spread / Toxic Barrage) double-dip Lash. Heat that combines toxin away is a loss. Cold for Viral if progenitor is not already Cold. Galvanized Hell + Point Blank/Savvy for the first kill. Arcane: **Primary Blight** or **Arcane Rage**.
