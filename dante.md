# Dante — Infernal Symphony

High-strength, high-duration Triumph + Tragedy caster. **Do not Helminth over 2/3/4.**

## Frame (~5 Forma)

Aura **Corrosive Projection**. Exilus **Preparation**.

| 2 | Blind Rage |
| 3 | Primed Continuity |
| 4 | Constitution |

| 7 | Primed Flow |
| 8 | Equilibrium |
| Arcane 1 | Arcane Impetus |
| Arcane 2 | Arcane Concentration |

**~243% Strength, ~207% Duration, 145% Range, 45% Efficiency.** Impetus can add up to **+78% Strength / +39% Efficiency**. Concentration snapshots **+60% Duration** onto Final Verse.

Archon Stretch needs Electricity on Noctua/Wordwarden.

## Shards

**2 Amber** casting speed. **3 Crimson** strength. Madurai for more cast speed + strength.

## Noctua

**Viral + Electric** so Wordwarden procs Archon Stretch and Impetus.

Hornet Strike, Galvanized Diffusion, Lethal Torrent, Galvanized Shot, Pistol Elementalist, Primed Pistol Gambit, Primed Target Cracker, Frostbite + Stormbringer.

**Tome:** Xata Invocation (energy) or Vome Invocation (strength); **Jahu Canticle** for armor/shield strip.

**Arcane:** Secondary Encumber.

Wordwarden copies Noctua’s mods while holstered.

## Play

1. **Triumph:** `2 → 2 → 4`
2. **Pageflight:** `3 → 2 → 4`
3. **Wordwarden:** `2 → 3 → 4`
4. Nuke: Dark Verse into a crowd, then **Tragedy:** `3 → 3 → 4`

Keep 1–3 up. Tragedy detonates Slash / Heat / Toxin DoTs.

## Helminth (optional)

**Roar over Noctua (1) only.** Swap Constitution → Transient Fortitude, aura → Growing Power, arcanes → Impetus + Truculence.
