# Koumei — Circuit / Config A

Range first. Strength last. Omamori (3) is the tank.

Cave uses **Config A** when it is 40+ capacity. Do not walk in on empty.

## Config A

| Slot | Mod |
| --- | --- |
| Aura | Dreamer’s Bond |
| 1 | Stretch |
| 2 | Overextended *(or Augur Reach)* |
| 3 | Streamline |
| 4 | Flow |
| 5 | Fast Deflection |
| 6 | Adaptation *(Vitality if no Adaptation)* |
| 7 | Rolling Guard *(Intensify if no RG)* |
| 8 | Equilibrium *(or Intensify if 7 was Rolling Guard)* |

Empty arcanes are fine until Impetus or Aegis.

## Play

1. **Omamori (3)** always on. Recast at 5 charms or less.
2. **Omikuji (2)** on cooldown. In Duviri it opens the **Decree picker**.
3. **Kumihimo (1)** threads on the lane.
4. **Bunraku (4)** dump statuses, then shoot.

Triple sixes: Omikuji skips the challenge, Omamori full invuln until those charms are gone.
