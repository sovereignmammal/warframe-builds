# Scyotid — Config A (Oraxia hip)

Signature throwing knives. **No signature bonus.** Alt-fire: **15m** snare, **~6s** paralyze, pulls **8 × multishot**, **4 ammo**. Snare damage **does not scale**. Multishot is the grab.

Not Dual Tox. Not Mesa (Brakk). Not Gammacor’s slot.

Silken Stride extra Toxin **does** apply (this is not an Incarnon).

## Elements

Pestilence + Jolt combine first → **Corrosive**. Innate Toxin dumps into that pool. Puncture leftover. Fine — the snare does not need Toxin stacks.

**Next:** Primed Target Cracker. V-forma that 9-cost slot.

## Arcanes

- **Empowered** — current. Always on. Flat +750, so it is not a god pick on a ~3k shot.
- **Merciless** — if the hip is *killing* the clump.
- **Enervate** — alt-fire cannot crit, so it banks stacks.
- **Not Encumber** — one extra proc per instant. A snare-ball wastes it. Encumber stays on Gammacor / Nukor / Epitaph.
